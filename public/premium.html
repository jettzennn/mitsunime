Premium Mitsunime memberi aksesori profil eksklusif: border, background, bingkai avatar, lencana, dan efek nama. Semua episode tetap bisa ditonton siapa pun yang sudah login — Premium tidak mengunci konten apa pun.

Kode Diskon

Selesaikan Pembayaran

  1. Buka halaman pembayaran Midtrans lewat tombol di bawah.
  2. Selesaikan pembayaran di sana.
  3. Kembali ke halaman ini, lalu tekan "Cek Status Pembayaran".
  4. Bila pembayaran terkonfirmasi, transaksi menunggu persetujuan admin — Premium aktif setelah admin menyetujui.
Buka Halaman Pembayaran

Bayar dengan QRIS

Kode QRIS belum diatur admin. Minta admin mengatur kode QRIS dulu, atau coba lagi nanti.

  1. Pindai kode QRIS di atas dengan aplikasi pembayaran apa pun (DANA, GoPay, OVO, m-banking).
  2. Bayar tepat sesuai jumlah paket.
  3. Isi referensi atau nama pengirim (opsional) dan unggah bukti bayar (JPG/PNG/WebP, maks. 2 MB).
  4. Tekan "Kirim Transaksi". Premium aktif setelah admin memeriksa bukti dan menyetujui.

Bukti membantu admin memeriksa pembayaran kamu. Bila tidak ada bukti, admin memeriksa dari mutasi di aplikasi pembayarannya.
